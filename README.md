# Museo Interactivo de Semana Santa

Web app interactiva para el museo de Semana Santa con experiencia 3D y diseño premium.

## Estructura del Proyecto

```
WEB-APP-MONJAS-NUEVO/
├── index.html          # Splash screen / Página de inicio
├── js/
│   └── app.js         # Lógica principal de la aplicación
├── css/               # Estilos personalizados (próximamente)
├── assets/            # Imágenes y recursos (próximamente)
└── README.md          # Este archivo
```

## Tecnologías

- **HTML5** - Estructura semántica
- **TailwindCSS** - Framework de estilos
- **JavaScript** - Interactividad
- **Google Fonts** - Tipografía Noto Serif
- **Material Symbols** - Iconografía

## Características

- ✨ Diseño premium con efectos glassmorphism
- 🎨 Paleta de colores personalizada para Semana Santa
- 📱 Diseño responsive (mobile-first)
- 🌙 Modo oscuro elegante
- ⚡ Animaciones suaves y micro-interacciones
- 🏛️ Temática de museo con texturas sutiles

## Desarrollo Local

Simplemente abre `index.html` en tu navegador o usa un servidor local:

```bash
# Con Python
python -m http.server 8000

# Con Node.js
npx serve
```
